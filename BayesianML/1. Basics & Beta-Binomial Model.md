
# Framework for Bayesian Machine Learning
In classical machine learning, *different parameters* for a model might be *consistent* with the dataset we're analyzing (as measured by training loss). The choice is chosen usually arbitrarily. In **Bayesian ML**, we take them *all* **M** into account in some form.

We also work with *posterior distributions*, weighting how much each parameter by the data. Simply means *some* solutions may be more plausible and should have higher weights when we predict new points. Assuming still **M** models:
$$ \hat{y}=\sum_{i=1}^{M}P(x^*|w_i)P(w_i|y) $$
Often we can have *infinite* solutions, so it is replaced with an integral. Called **marginalization**:
 $$\hat{y}=\int P(x^*|w_i)P(w_i|y)\text{ d}w$$ 
 This gives us *uncertainty quantification*. Usually split into *epistemic* and *aleatoric* uncertainty: the first can be reduced with more data, while the latter can't and is inherent to measuring noise etc.

**To sum:**
- Parameters *and* data represented by *probability distributions*
- Bayes' Rule is important: $P(W|Y)=\frac{P(Y|W)P(W)}{P(Y)}$
- *Likelihood* $P(Y|W)$: Distribution of $y$ given a specific set of parameters $w$.
- *Prior* $P(W)$: Prior belief about the parameters *w* before seeing data.
- *Posterior* $P(W|Y)$: contains all the knowledge about parameters *after* observing $y$.

They are ==all distributions==

**Priors:**
- Can encode domain knowledge
- Can help prevent overfitting
- Can generate artificial datasets from the model

# Beta-Binomial Model & Maximum Likelihood Estimation

### Recap: Bernoulli Distribution

For a binary variable in $x\in \{0,1\}$, where 1 represents the "sucess", then

$$P(x=1|\theta)=\theta,P(x=0|\theta)=1-\theta$$

Where $0\leq\theta\leq1$.

$$\text{Ber}(x,\theta)=\theta^x(1-\theta)^{1-x}$$**Mean**: $\mathbb{E}[x]=\theta$
**Var**: $\mathbb{V}[x]=\theta(1-\theta)$

### Recap: Binomial Distribution

*N* independent Bernoulli Trials $x_i\sim\text{Ber}(\theta)$ for $i=1,\cdots,N$, the number of successes $y=\sum x_i$ follows a binomial distribution:

$$ \text{Bin}(y|N,\theta) = \begin{pmatrix} N \\y \end{pmatrix}\theta^y(1-\theta)^{N-y} $$
**Mean**: $\mathbb{E}[x]=\sum_i \mathbb{E}[x_i] =N\theta$

#### Example of Maximum Likelihood Estimation (MLE) w. Binomial Distribution

Assume we have a dataset $D=\{x_1,\cdots,x_N\}$ of N independent Bernoulli Trials with probability $\theta$. How to estimate this $\theta$?

First, let $y=\sum_i x_i$ define number of successes. Then we define the maximum likelihood as $\mathcal{L}(x)\equiv P(y|\theta)$, where $P(y|\theta)$ follows the Binomial distribution above.

The ==likelihood function measures the *probability* of the observed data given the parameter value of theta== (or a similar variable). We want to *maximize* this probability, so we *differentiate it* and *equal it to 0*, and *solve for $\theta$*. Often we take the **log** for a log-maxmimum likelihood. It does not sum to 1 over the different values of $\theta$!

For the binomial above it would look like:
$$\begin{align}
\log\mathcal{L}(x)&=\log\left[ \begin{pmatrix}N \\ y\end{pmatrix}\theta^y(1-\theta)^{N-y} \right] \\
&=\log\left[\begin{pmatrix}N \\ y\end{pmatrix}\right]+y\log(\theta)+(N-y)\log(1-\theta)
\end{align}$$
We maximize this, by finding the derivative of it, and equaling it to 0, then isolate $\theta$:
 $$\begin{align}(\mathcal{L}(x))'&=(\log\left[\begin{pmatrix}N \\ y\end{pmatrix}\right]+y\log(\theta)+(N-y)\log(1-\theta))' \\
 &= \frac{1}{\theta}y-\frac{1}{1-\theta}(N-y)=0
 
 \end{align}$$
 Isolation for $\theta$ then gives:
 $$\hat{\theta}_{MLE}=\frac{y}{N}=\frac{1}{N}\sum_{i=1}^Nx_i$$
 Say we have data that now says we have 0 clicks in 3 tries (D = \{0,0,0\}, N=3), then the MLE of $\theta$ in a Binomial setting would be $0/3=0$. If we then ask with this, how probable is it the next 50 clicks are also negative, then if we plug our estimator into the binomial distribution, then it thinks that it ==100% possible that no one clicks==. This is not really reasonable.

It is a problem of **overfitting**; we're using MLE when we have little data, and that is exactly prone to overfitting. We can overcome this though:

### How to choose prior $p(\theta)$?

It should reflect our assumptions. Sometimes a *uniform* prior is good, when we have no clue. Other times, we might know something that carries some information about what we know.

**Prior Examples**:

- (Weakly) Informative Prior
- Priors for mathematical convenience

## Beta Distribution
Is a family of distributions for a random variable $\theta\in[0,1]$ ==in the unit interval==. It can be chosen as a ==*prior distribution*== usually, as it is in that interval.

The density is given by:
$$p(\theta|a,b)=\frac{1}{B(a,b)}\theta^{a-1}(1-\theta)^{b-1}$$
where $B(a,b)$ is a normalization constant given by:
$$B(a,b)=\frac{\Gamma(a)\Gamma(b)}{\Gamma(a+b)}, \Gamma(x)=\int_0^\infty x^{z-1}e^{-x}$$
with $\mathbb{E}[\theta] = \frac{a}{a+b}$, $\mathbb{V}[\theta]=\frac{ab}{(a+b)^2(a+b+1)}$

**Functional Form**:
Recall, the density function must sum to 1, and hence:
$$ \int_\theta p(\theta|a,b) = \int_\theta \frac{1}{B(a,b)}\theta^{a-1}(1-\theta)^{b-1} = \frac{1}{B(a,b)}\int_\theta\theta^{a-1}(1-\theta)^{b-1} = 1 $$

So this means that, if I multiply with $B(a,b)$ on both sides:

$$ \int_\theta\theta^{a-1}(1-\theta)^{b-1} = B(a,b) $$ This is smart, as it allows some neat tricks. **Example:** $$p(\theta)\propto\theta^5(1-\theta)^4=\theta^{6-1}(1-\theta)^{5-1}$$ From which we can ==conclude== that $a=6,b=5$ and we can compute the normalization constant:
$$ \int_\theta\theta^{6-1}(1-\theta)^{5-1} = B(6,5) $$The ==functional form== is then $f(\theta)=\theta^{a-1}(1-\theta)^{b-1}$

## Binomial Likelihood with Beta Prior

If we combine the binomial distribution with a Beta distribution Prior, the then ==the posterior distribution follows a beta distribution==!

Assume $p(y|\theta)$, the likelihood function, follows binomial, and that $p(\theta)$, the prior, follows a beta. For the beta one, we denote it $a_0,b_0$ for ==its parameters, with subscript 0== because it is the prior!

We can see this because then with Bayes' we have:

$$\begin{align}
p(\theta|y) &= \frac{p(y|\theta)p(\theta)}{p(y)} \propto p(y|\theta)p(\theta) \\
&= \begin{pmatrix} N \\y \end{pmatrix}\theta^y(1-\theta)^{N-y}\frac{1}{B(a,b)}\theta^{a-1}(1-\theta)^{b-1} \propto \theta^y(1-\theta)^{N-y}\theta^{a-1}(1-\theta)^{b-1} \\
&= \theta^{y+a_0-1}(1-\theta)^{N-y+b_0-1} \\
&\propto \text{Beta}(\theta|y+a_0,N-y+b_0)
\end{align}$$

When we use $\propto$ it is because we leave out terms that is not related to $\theta$. We see that the functional form ends up being exactly like the *beta* distribution's functional form, and we can see that in the posterior case we get $a=y+a_0,b=N-y+b_0$

The *beta* distributions is a ==conjugate== to the binomial distribution exactly because the posterior is of the same *functional form* as the prior!

==The posterior mean== then equates to $\mathbb{E}[\theta|y]= \frac{a}{a+b} = \frac{y+a_0}{a_0+b_0+N}$.

## Beta-Binomial Model
Above shows the requirements for the beta-binomial model, but is summarized here. The key equations for the model are given by

$$\begin{align}
p(\theta) &= \text{Beta}(\theta|a_0, b_0) && \text{(Prior)}\\
p(y|\theta) &= {N \choose y} \theta^y (1-\theta)^{N-y}&&\text{(Likelihood)}\\
p(\theta|y) &= \text{Beta}(\theta|a_0 + y, b_0 + N-y)&&\text{(Posterior)}
\end{align}$$

for the dataset $\mathcal{D} = \left\lbrace N, y \right\rbrace$.

**Example**: Given that $N=20,y=4$, and we assume a *beta* prior with $a_0=b_0=2$, what is the:
- **Prior mean**: from the *beta distribution*, we know the mean is $\frac{a}{a+b}=\frac{2}{4}=0.5$
- **Posterior Distribution Parameters**: The function form allows us to glance this; inserting we get: $\theta^{y+a_0-1}(1-\theta)^{N-y+b_0-1} = \theta^{4+2-1}(1-\theta)^{20-4+2-1}$ from which we see that $a=6,b=18$
- **Posterior Mean**: We use the parameters we just found and find it to be $\frac{a}{a+b}=\frac{6}{6+18} = \frac{6}{24} = 0.25$

## Calculation Posterior Summaries in Practice (Monte Carlo Estimation)

When we have a posterior, we sometimes want to know the estimate of the *posterior mean* or some probability for the tail of the posterior, then if it is hard to derive by hand, we can do **Monte Carlo Estimation**:

$$ \mathbb{E}_{p(\theta|y)}[\theta] = \int_\theta \theta p(\theta) \approx \frac{1}{S}\sum_{i=1}^S\theta^{(i)},\quad \theta^{(i)}\sim p(\theta|y)$$
Which also works for *functions* of $\theta$:
$$ \mathbb{E}_{p(\theta|y)}[f(\theta)] = \int_\theta f(\theta) p(\theta) \approx \frac{1}{S}\sum_{i=1}^Sf\left(\theta^{(i)}\right),\quad \theta^{(i)}\sim p(\theta|y)$$

We can do the same with fractions of the probabilities. Say we want the tail probability of $P(\theta < 0.15|y)$:

$$ P(\theta<0.15|y) = \int_0^{0.15}p(\theta|y)\text{ d}\theta=\int_\theta\mathbb{I}[\theta<0.15]p(\theta|y) \approx \frac{1}{S}\sum_{i=1}^S\mathbb{I}[\theta^{(i)}<0.15], \quad \theta^{(i)}\sim p(\theta|y)$$
